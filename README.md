## Descrição

O Dog Explorer é uma aplicação web desenvolvida com HTML, CSS e JavaScript que permite ao usuário pesquisar diferentes raças de cães. A aplicação consome uma API pública utilizando a função `fetch()` e exibe informações sobre a raça pesquisada de forma organizada e intuitiva.

---

## API utilizada

**TheDogAPI**

Documentação:
https://thedogapi.com/

Endpoint utilizado:

```
https://api.thedogapi.com/v1/breeds/search?q={nome_da_raca}
```

---

## Funcionalidades

- Pesquisar uma raça de cachorro.
- Exibir o nome da raça.
- Exibir o peso.
- Exibir a altura.
- Exibir a expectativa de vida.
- Exibir o temperamento (traduzido para português quando disponível).
- Exibir o grupo da raça.
- Exibir a origem da raça.
- Informar quando a raça não for encontrada.
- Exibir mensagem de carregamento durante a consulta.
